# Repository Instructions

## Skill creation

- Create and maintain skills using current, well-established prompt-engineering best practices.
- Keep instructions clear, specific, testable, and free of ambiguity.
- Define the skill's purpose, activation criteria, constraints, expected workflow, and output format explicitly.
- Keep every skill compatible with Claude Code, Codex, Kiro CLI, and OpenCode.
- Document platform-specific setup and include required adapters when behavior differs.
